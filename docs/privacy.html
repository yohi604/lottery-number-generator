개인정보 처리 안내

적용일: 2026년 11월 9일 · 현재 공개 테스트 버전 기준

1. 사이트가 직접 요청하는 정보

회원가입이나 로그인, 이름·이메일·전화번호 입력 기능이 없습니다. 자체 서버나 데이터베이스로 생성 번호와 저장 번호를 전송하지 않습니다. 결제 정보도 요청하지 않습니다.

2. 브라우저에 저장하는 정보

이용자가 저장 버튼을 누르면 복권 유형, 번호, 저장 시각을 현재 브라우저의 localStorage에 저장합니다. 저장 키는 lottery-number-generator:v1이며, 새로고침 후 보관함을 다시 표시하기 위한 용도로 사용합니다. 다른 기기·브라우저·도메인과 자동 동기화하지 않습니다.

별도 만료 기간은 두지 않으며, 이용자가 삭제하거나 브라우저가 데이터를 지울 때까지 보관될 수 있습니다. 시크릿 모드 종료, 브라우저 데이터 삭제, 저장 공간 정책에 따라 데이터가 사라질 수 있습니다. 공용 기기에서는 같은 브라우저를 이용하는 사람이 저장 번호를 볼 수 있습니다.

3. 삭제 방법

보관함의 개별 삭제 또는 복권별 전체 삭제 기능을 사용하세요. 전체 삭제에는 확인 절차가 있으며 선택한 복권 보관함만 비웁니다. 이 사이트는 다른 서비스의 localStorage 키를 지우지 않습니다. 브라우저 설정에서 사이트 데이터를 삭제하는 방법도 있지만, 같은 출처의 다른 웹사이트 데이터까지 함께 지워질 수 있습니다.

4. 복사 기능

복사 버튼을 누르면 선택한 번호를 기기의 클립보드에 기록합니다. 브라우저 권한 설정에 따라 복사가 제한될 수 있으며, 이 경우 직접 선택해 복사할 수 있는 창을 제공합니다. 이 사이트가 기존 클립보드 내용을 읽는 기능은 없습니다.

5. 호스팅 및 외부 링크

GitHub Pages에서 페이지를 제공하므로 접속 과정에서 IP 주소 등 일반적인 웹 요청 정보가 호스팅 제공자에 전달되거나 처리될 수 있습니다. 이는 사이트 코드의 번호 저장 기능과 별개입니다. 자세한 내용은 GitHub 개인정보 처리방침을 확인해 주세요.

동행복권이나 GitHub 등 외부 링크를 누르면 해당 사이트로 이동하며, 이후의 정보 처리는 해당 서비스의 정책에 따릅니다. 외부 글꼴·광고·방문 분석 스크립트는 현재 사용하지 않습니다.

6. 쿠키와 광고

현재 사이트 코드에는 광고, 방문 분석, 추적용 쿠키를 설정하는 기능이 없습니다. localStorage는 위에서 설명한 번호 보관 용도로 사용합니다. 앞으로 광고나 분석 기능을 도입한다면 실제 사용 서비스와 정보 처리 범위를 명시하고 필요한 안내 및 동의 절차를 준비합니다.

7. 안내 변경

기능이나 호스팅 방식이 달라지면 이 페이지와 적용일을 갱신합니다. 현재 없는 수집 기능이나 운영자 정보를 기재하지 않습니다.
