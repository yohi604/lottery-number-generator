작은 즐거움, 간편한 번호 선택

복잡한 가입 없이 번호를 만들고, 마음에 드는 번호를 이 브라우저에 보관하는 무료 도구입니다.

무엇을 할 수 있나요?

로또 6/45와 연금복권 720+ 번호를 1·5·10게임씩 만들 수 있습니다. 생성한 번호를 복사하거나 복권별 보관함에 저장하고 삭제할 수 있습니다. 저장 날짜도 함께 확인할 수 있습니다.

번호는 어떻게 만들어지나요?

브라우저가 제공하는 보안 난수 기능을 사용하며, 숫자를 원하는 범위로 바꿀 때 특정 숫자가 더 자주 선택되는 편향을 피하도록 구현했습니다. 로또는 1~45 중 중복 없는 6개를 뽑아 정렬합니다. 연금복권은 1~5조와 여섯 자리 숫자를 각각 독립적으로 생성합니다.

게임마다 독립적으로 생성하므로 서로 다른 게임에는 같은 조합이 나올 수 있습니다. 연금복권의 앞자리 0과 반복 숫자는 정상입니다. 번호 생성은 당첨 예측이 아니며 통계로 당첨 가능성이 높아진다고 안내하지 않습니다.

저장되는 위치

저장 번호와 날짜는 현재 브라우저의 localStorage에만 보관됩니다. 다른 기기나 브라우저와 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하거나 시크릿 창을 닫으면 사라질 수 있습니다. 개인정보 처리 안내에서 자세히 확인할 수 있습니다.

제공하지 않는 기능

복권 판매·결제·베팅·구매 예약·실시간 당첨 확인·번호의 실제 구매 가능 여부 확인은 제공하지 않습니다. 번호 생성이나 저장만으로 복권이 구매되지 않습니다.

공식 서비스와의 관계

본 사이트는 동행복권과 제휴하거나 동행복권이 운영하는 공식 서비스가 아닙니다. 공식 로고를 사용하지 않습니다. 복권 이름은 지원하는 번호 형식을 설명하기 위해 사용합니다. 규칙은 로또 공식 안내와 연금복권 공식 안내를 참고합니다.

현재 운영 형태

개발 및 공개 테스트를 위한 정적 웹사이트입니다. 현재 광고 코드나 방문 분석 도구를 넣지 않았습니다. 사이트에 자체 회원가입이나 유료 기능은 없습니다. 광고 등 기능을 추가할 때는 운영 안내와 개인정보 안내를 실제 변경 사항에 맞게 갱신합니다.

오류를 발견했다면

공개된 GitHub 저장소에서 코드와 사용 안내를 확인할 수 있습니다. 오류를 알릴 때 개인정보나 로그인 정보를 공개하지 마세요.
