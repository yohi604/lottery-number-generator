01

게임 수를 고르고 생성

1·5·10게임 중 골라 버튼을 누르세요. 다시 누르면 새 번호가 만들어집니다. 각 게임은 독립적으로 생성되어 게임 사이에는 같은 번호가 나올 수 있어요.

02

복사하거나 보관하기

한 게임씩 또는 전체 번호를 복사할 수 있어요. 저장한 번호는 새로고침해도 유지됩니다. 같은 번호는 보관함에 한 번만 저장돼요.

03

로또는 1~45 중 서로 다른 6개, 연금복권은 1~5조와 000000~999999입니다. 번호 생성과 저장은 실제 복권 구매나 예약이 아닙니다.

FAQ

궁금한 점을 모았어요

이 번호로 당첨 확률이 높아지나요?

아니요. 각 복권의 모든 유효한 번호 조합은 같은 당첨 확률을 갖습니다. 이 서비스는 과거 당첨번호나 통계로 번호를 추천하지 않으며 당첨을 예측하지 않습니다. 브라우저의 보안 난수를 이용해 무작위 번호를 만듭니다.

연금복권은 0으로 시작하거나 같은 숫자가 반복돼도 되나요?

네. 여섯 자리는 각각 0~9를 사용할 수 있어 3조 012345, 1조 000000 같은 번호도 형식상 유효합니다. 조 번호와 각 자릿수는 독립적으로 생성됩니다. 실제 구매 가능 여부나 판매 상태는 확인하지 않습니다.

로또 보너스 번호는 왜 없나요?

구매자가 선택하는 번호는 6개입니다. 보너스 번호는 공식 추첨에서 2등 당첨을 구분할 때 사용하는 번호이므로 이 생성기에서는 따로 생성하지 않습니다.

저장한 번호가 다른 기기에서도 보이나요?

아니요. 번호와 저장 날짜는 현재 브라우저의 localStorage에만 보관됩니다. 계정이나 서버 동기화 기능은 없습니다. 다른 기기로 옮기려면 번호를 복사해 별도로 보관하세요.

저장이나 복사가 안 될 때는 어떻게 하나요?

브라우저의 저장 차단 설정이나 저장 공간 부족 때문에 저장이 실패할 수 있습니다. 이때 실패 안내가 표시됩니다. 복사 권한이 막힌 경우 직접 선택해서 복사할 수 있는 창을 제공합니다. 중요한 번호는 별도로 기록하세요.

번호를 저장하면 복권이 구매되나요?

아니요. 번호 생성·복사·저장은 기록을 위한 기능일 뿐입니다. 복권 판매, 결제, 베팅, 구매 예약, 당첨 확인 기능은 제공하지 않습니다.
